# 💫 About Me:
Halo, perkenalkan saya Muhammad Isa Daud! 👋 Saya adalah mahasiswa semester satu program studi Teknik Informatika di UBP Karawang, dengan latar belakang SMK jurusan Teknik Komputer dan Jaringan (TKJ). Saat ini, saya masih berstatus sebagai pembelajar pemula yang sedang antusias mengeksplorasi dunia coding, khususnya di bidang Frontend Development (HTML, CSS, dan JavaScript). Akun GitHub ini adalah buku catatan digital saya untuk menyimpan progres belajar, bereksperimen dengan kode, dan mengunggah project latihan sederhana, seperti membuat antarmuka web sejarah militer atau merangkai prototipe e-commerce dasar. Meskipun kode yang saya tulis mungkin belum sempurna, saya terus belajar dengan harapan bisa membangun website yang lebih interaktif dan perlahan mulai memahami pembuatan aplikasi Android. Kalau sedang butuh rehat dari bug atau error, saya biasanya bermain game taktis seperti War Thunder dan Hearts of Iron IV, mendalami sejarah militer, atau bersantai sambil mendengarkan lagu-lagu dari Sheila On 7 dan KLa Project.
